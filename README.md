# Figma-to-React Product Workshop Primer

A 2-day, portfolio-oriented workshop for hybrid UX/UI Designers + React Developers who need credible, business-facing product artifacts for interviews, internal workshops, or portfolio growth.

## Who this is for
- UX/UI Designers who also collaborate deeply in front-end implementation
- React Developers who want stronger product/design process fluency
- Product teams preparing for design sprints, interview prep, or modernization initiatives

## What you will produce in 2 days
By the end of this workshop, you should have multiple portfolio-quality artifacts:
- 1 selected business brief scoped as a realistic product challenge
- Problem framing, user/role map, and workflow model
- IA, prioritized task model, and low-fidelity flow set
- High-fidelity Figma screens and interaction prototype slices
- Design-system + accessibility decisions documented for handoff
- React implementation readiness package (states, behavior, constraints)
- Case study narrative ready for interviews and presentations

## How to Use This Workshop (2 Days)
1. Pick one brief from [`briefs/`](./briefs/).
2. Move through modules in order in [`modules/`](./modules/).
3. Use checklists in [`quick-reference/`](./quick-reference/) to maintain speed and quality.
4. Apply reusable guidance from [`patterns/`](./patterns/).
5. Package outputs using [`portfolio-packaging/`](./portfolio-packaging/) and [`deliverables/`](./deliverables/).

## Day 1: Product Framing to Structural Design
- Module 01: Business context and product framing
- Module 02: Users, roles, JTBD, workflow discovery
- Module 03: Information architecture and task prioritization
- Module 04: Low-fidelity flows and wireframes
- Module 05: Design system thinking, components, accessibility baseline

**Day 1 outcome:** a defensible problem definition and complete low-fidelity product direction grounded in business and workflow realities.

## Day 2: High-Fidelity Design to React Handoff
- Module 06: High-fidelity UI and interactive prototyping in Figma
- Module 07: React handoff, states, interaction logic, implementation readiness
- Module 08: Portfolio case study and presentation narrative

**Day 2 outcome:** polished prototype slices plus a production-aware handoff and interview-ready story.

## Expected outputs and deliverables
This workshop is intentionally business-facing. Your outputs should demonstrate:
- Product reasoning (problem framing, stakeholder logic, KPI alignment)
- UX process strength (roles, workflow analysis, IA, usability choices)
- Visual/UI craft (hierarchy, consistency, enterprise clarity)
- Systems thinking (components, variants, states)
- React handoff readiness (interaction behavior, state logic, responsive expectations, accessibility requirements)

Use this repository as a guided structure to create work that feels credible in healthcare, internal tooling, and enterprise modernization contexts.
