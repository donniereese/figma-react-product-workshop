# Approvals and Workflow Patterns

## Core principles
- Make request status explicit at every step
- Show decision rationale and audit history
- Preserve momentum with clear next actions

## Reusable patterns
- Queue views segmented by urgency/SLA risk
- Request detail with summary-first information architecture
- Approval action cluster with conditional requirements
- Escalation, reassignment, and delegation controls

## Implementation-aware notes
- Document state machine transitions for each request status.
- Align permissions with available actions per role.
