# Modernization and Redesign Patterns

## Core principles
- Modernize by workflow slice, not page-by-page aesthetics
- Preserve mission-critical behavior before introducing new complexity
- Use parallel run periods to de-risk migration

## Reusable patterns
- Legacy pain audit mapped to workflow impact
- Bridge UI for old/new coexistence during rollout
- Feature-flagged modernization releases
- Task-level parity checklist before deprecating legacy screens

## Implementation-aware notes
- Track backward compatibility assumptions in handoff.
- Define rollout metrics and rollback triggers.
