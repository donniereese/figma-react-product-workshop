# Form-Heavy Enterprise UX Patterns

## Core principles
- Reduce cognitive load via progressive disclosure
- Prevent errors with structured input and validation timing
- Keep users oriented in long multi-step flows

## Reusable patterns
- Sectioned forms with completion indicators
- Inline validation with resolution guidance
- Dependency-aware fields that explain lock/unlock logic
- Save draft and resume with last-edited context

## Implementation-aware notes
- Document field-level validation rules and dependencies.
- Clarify autosave vs explicit-save behavior.
