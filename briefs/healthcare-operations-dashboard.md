# Brief: Healthcare Operations Dashboard

## Business context
A regional healthcare network needs better visibility into patient throughput, staffing constraints, and discharge delays across multiple facilities.

## Users and roles
- Operations Manager
- Unit Charge Nurse
- Bed Coordination Specialist
- Executive Viewer

## Problem statement
Current reporting is fragmented across legacy dashboards and spreadsheets, causing delayed decisions and poor cross-unit coordination.

## Constraints
- HIPAA-aware data visibility by role
- Existing EHR integrations are limited
- Teams need near-real-time visibility during peak hours

## Success metrics / KPIs
- Reduced average discharge processing time
- Reduced bed assignment delay
- Increased shift-level throughput visibility
- Fewer manual status update escalations

## Suggested deliverables
- Problem framing and workflow map
- Dashboard IA with alert/priority model
- Lo-fi and hi-fi dashboard flow slice
- State and role-based visibility matrix for React handoff

## Why this is portfolio-worthy
This project demonstrates high-density information design, operational workflow understanding, and role-based UX under regulated healthcare constraints.
