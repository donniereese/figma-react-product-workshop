# UX Workshop Checklist (2-Day Sprint)

- [ ] Select one business brief and define scope boundaries
- [ ] Confirm primary roles and top 3 workflow tasks
- [ ] Define measurable success outcomes
- [ ] Build current-state flow and friction map
- [ ] Produce IA and task-priority matrix
- [ ] Draft lo-fi flows including edge/error paths
- [ ] Build hi-fi prototype slice for key scenario
- [ ] Document component/state/accessibility expectations
- [ ] Prepare React handoff and case study narrative
